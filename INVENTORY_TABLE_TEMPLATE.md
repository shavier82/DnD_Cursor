## Key Features:

### ✓ Equipped Column
- **✓** = Currently equipped/worn
- **—** = In inventory but not equipped

### Weapons
- **Attack**: Total attack bonus (+prof +ability +magic)
- **Damage**: Dice + modifier + damage type
- **Properties**: Finesse, Versatile, Thrown, etc.
- **Special Effects**: Magic bonuses, enchantments

### Armor
- **AC Bonus**: Total AC provided (base or +X)
- **Type**: Heavy/Medium/Light/Shield
- **Properties**: Requirements, disadvantages
- **Special Effects**: Magic properties

### Magic Items
- **Equipped/Attuned**: Shows if currently attuned
- **Properties**: What it does
- **Charges**: Current/max charges if applicable

### General Inventory
- **Quantity**: How many you have
- **Weight**: Total weight in pounds
- **Notes**: Special info
